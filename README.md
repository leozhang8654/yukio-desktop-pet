# Yukio 开发进度网站

[打开网站](https://leozhang8654.github.io/yukio-desktop-pet/)

查看已经完成的工作、接下来的安排和完整计划。每一步都能展开，了解具体做了什么、为什么这样做、怎样检查，以及还有哪些限制。

这是最近一次发布的开发进度。页面每分钟检查新版；未发布的本机修改不会自动出现。电脑上的实时活动、聊天内容、活动记录簿和密钥不在这个网站中。本机工作台已能整理请求与结果、查看明确的助手关系，并手动解释单条活动或有明确范围的一段记录。Mac 独立试用入口已交付本机，日常使用验收待完成；完整任务总结仍在开发。这个公开页面不连接你的内网模型。

## 本分支内容

`codex/activity-progress-pages` 是网站的独立发布分支，使用 GitHub Pages 从根目录发布；它不是桌面 App 的源码或版本发布分支。

- `index.html`、`style.css`、`app.js`：无需安装依赖的页面和交互。
- `status.json`：经过核查并整理的公开开发进度，`collector` 固定为空。
- `.nojekyll`：让 GitHub 原样提供静态页面。

本地查看可运行 `python3 -m http.server 8767 --bind 127.0.0.1`，然后打开 `http://127.0.0.1:8767/`。也支持部署到仓库名称所在的子路径。

## 后续维护

确认新成果和验证结果后，编辑 `status.json` 中的公开进度及 `publication.exported_at`；不要加入私人活动、凭据或电脑路径。将网站文件提交到本分支，GitHub Pages 会重新发布，已打开的页面随后会读取新进度。修改页面脚本或样式后应重新加载页面。

本机开发目录有 `tools/activity-progress/export_public.py`，可从维护中的进度记录导出这六个文件。该导出器不读取本机记录器的数据。公开前仍应检查文字内容。

网站发布不表示桌面 App 已替换或整个活动观察系统已完成。Windows 按用户选择暂缓实机验证；长期使用、完整任务总结和产品正式发布等未完成事项在完整计划里明确列出。
