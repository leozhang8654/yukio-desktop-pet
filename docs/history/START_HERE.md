# 雪绪：Cloud 接续包

目标：制作一个独立桌面播放器，让**同一只雪绪**根据 Codex 的当前活动自动切换动作。目标桌面是用户的 macOS。

请先阅读 `HANDOFF.md`，再看 `PLAYER_REQUIREMENTS.md`。打开 `preview.html` 可以离线手动预览现有动作。

## 当前成果

- 一只角色，七套活动动作，加一个稳定的电脑桌默认工作画面。
- 已修正平板手部：屏幕朝上，支撑手托住边缘下方，操作手指触摸正面屏幕。
- 原版左右跑动已恢复；旧跳跃、欢呼和蹲缩变形不再使用。
- 当前原生宠物的工作槽位暂时是新版托腮；这是用户最后要求的临时调整。
- **独立桌面程序、实时活动接入、活动分类、防抖切换均未实现。** HTML 只是手动演示。

## 文件导航

| 文件／目录 | 用途 |
| --- | --- |
| `CONTINUE_PROMPT.txt` | 上传后可直接发送的接续提示词 |
| `HANDOFF.md` | 已确认的需求、决策与当前状态 |
| `PLAYER_REQUIREMENTS.md` | 独立播放器的实现顺序和验收要求 |
| `assets/activities/` | 七套活动图条、默认电脑桌及动作映射 |
| `assets/base/` | 站立待机、原版左右跑动、平静交互、16 方向视线 |
| `native-current/` | 本机当前单宠物 v5 的快照，仅供参考和恢复 |
| `sources/` | 更高分辨率的生成源图，洋红底，需要提取透明背景后使用 |
| `references/` | 动作总览、平板修正图、生成提示词、图片尺寸清单 |
| `scripts/verify_package.py` | 无第三方依赖的完整性与引用检查 |
| `SHA256SUMS.json` | 打包文件校验值 |

Cloud 中解压后运行：

```sh
python3 scripts/verify_package.py
```
