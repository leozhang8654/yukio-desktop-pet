## 下载后怎么安装

### macOS

1. 双击 `Yukio-0.3.8-macOS.dmg`，打开专门的安装窗口。
2. 把左侧的 `Yukio.app` 拖到右侧的「应用程序 Applications」。更新旧版时先退出 Yukio，再拖入并选择替换。
3. 从「应用程序」打开 Yukio。若提示 Apple 无法验证，确认信任下载来源后，前往「系统设置 → 隐私与安全性」，找到 Yukio 并点击「仍要打开」。
4. 雪绪出现在屏幕右下角后，右键她打开设置，可将 Language 改成「中文」，或点击「播放模拟演示」。

安装步骤直接显示在安装窗口背景上。安装后可在 Finder 推出「Yukio 0.3.8」磁盘。旧 ZIP 包若只有 `Yukio.app`：选中它按 ⌘C，在 Finder 按 ⌘⇧A 打开「应用程序」，再按 ⌘V 粘贴。

### Windows

下载 `Yukio-0.3.8-Windows.exe` 后双击运行，无需安装 Python。若出现「Windows 已保护你的电脑」，确认信任下载来源后点击「更多信息 → 仍要运行」。

旧版 ZIP 仍保留在附件中；Mac 用户请优先下载上方的 DMG。
