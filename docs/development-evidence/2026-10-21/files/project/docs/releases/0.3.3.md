# Yukio 0.3.3 · 取消举牌按钮

macOS 和 Windows 的桌宠设置顶部新增大号“取消举牌 / Lower sign”图标按钮。点击设置外部即可关闭。正式版同时暂停独立助手页面与入口，再次打开程序进入紧凑设置。

点击放下当前完成牌，不打开聊天，不暂停跟随；新的任务完成后仍能正常举牌。没有完成牌时点击不会产生副作用。演示模式下作用于演示中的完成牌。

## 验证

- macOS：173 项测试通过，含大号图标按钮及动作绑定检查；已在桌面安装版本中打开设置并实际点击。
- Windows：224 项测试通过，含放下牌后不打开聊天、重复点击、下一轮仍可举牌的回归测试。
- Windows 成品在 GitHub Windows runner 上通过设置按钮、窗口内外点击、监听清理、右键重新打开及 100% / 150% 缩放验证：[构建记录](https://github.com/leozhang8654/yukio-desktop-pet/actions/runs/37157465779)。
- macOS 发布包包含 Apple silicon 和 Intel 架构，已通过签名完整性检查。
