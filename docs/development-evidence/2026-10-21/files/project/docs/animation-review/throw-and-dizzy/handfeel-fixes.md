# 手感与当前任务报告修复

按用户本次反馈，修复以下三项。动画样式留待后续修改，Windows 原生测试继续延后。

- **正常放置和抛掷分开**：松手时的指针速度达到 650 point/s 才抛掷；慢拖、轻放、快速移动后停手再释放，均使用原来的悬浮摆放。判定不受角色残余摆动影响。保存正常窗口位置，并使用 AppKit 实际窗口位移消除重复提放的坐标取整偏移。
- **当前任务报告恢复显示**：原逻辑把气泡窗口 `orderOut` 后只恢复透明度，窗口仍未显示。现在在抛掷结束、接住、抛掷中隐藏再显示后，刷新当前任务并重新显示窗口；短于一个业务 tick 的快速接住也覆盖。保留未发送的回答草稿。
- **悬浮时提起卡住**：原抓取路径保留冻结的飞行帧，拖动开始也直接返回。现在按下立即终止旧飞行计时器，按当前人物中心转入提起动画；可继续拖动、轻放或再次甩出。取消后的迟到移动／松手事件不会重启拖动或误打开聊天。

Swift 完整 191 项测试通过，其中新增真实 AppKit 窗口回归涵盖三种飞行阶段的接住、恢复提起动作、放置、再次抛掷、取消与任务报告可见性。随后对“抛掷中隐藏再显示”补充检查，相关原生窗口测试再次通过。Python 260 项，1 项跳过，其余通过；这些检查使用 Win32 替身，不能视作 Windows 原生通过。见 [测试摘要](handfeel-tests.json)。

桌面安装路径仍为 `/Users/developer/Desktop/Yukio.app`。包内 188 个资源文件已逐一核对，182 个 PNG/WebP 与上一桌面测试包完全一致；本轮资源只增加抛掷判定阈值，未修改动画、人物比例或任务报告字号。安装标记、二进制哈希与回退路径见 [安装记录](handfeel-installation.json)。本地测试版未发布 GitHub，原 0.4.1 发布版回退路径仍保留在先前的 [安装记录](local-installation.json)。

人工试用重点：拖到屏幕中间停一下再放开，应留在那里；明显甩手松开，应飞出；空中再次按住，应立即恢复提起并跟手；落地后，当前任务报告应重新出现。这里的原生自动检查来自真实窗口和生产回调，完整手工鼠标手感仍需用户试用确认。
