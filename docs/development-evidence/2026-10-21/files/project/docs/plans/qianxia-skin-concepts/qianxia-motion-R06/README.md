# 千夏动画 R06：动作节奏重做候选，尚未验收

在 R05 基础上只改动作：时间曲线、幅度、节奏、变换方式，以及补底的透明度缺陷。沿用 R08 已确认的 12 张源图、蒙版、补底与眼睛结构；R05 原封不动保留作对照，`before/` 是 R05 正式候选的完整副本。

## 怎么看

- **`compare.html`**：左 R05、右 R06，共用同一时钟和同一套眨眼，只比较动作。默认 192×208 实际尺寸、真实速度，可半速 / 四分之一速度、放大 2 倍、换背景、单格重播。
- `index.html`：R06 单独预览（与 R05 同款控件：新事件、同事件刷新、逐帧）。
- `review/QianxiaMotionPreview.app`：原生预览，按键同 R05（G 放大、S 慢速、空格暂停、F 逐帧、B 背景、N 新事件、U 同事件刷新）。

## 改了什么

**1. 动作曲线。** R05 每段过渡都用同一条对称 S 曲线，眼睛约 0.25–0.3 秒慢慢滑到目标，看起来像在漂。R06 按动作选曲线：眼睛 0.07–0.12 秒跳到目标后停住；手到位时减速并有一点回弹和安定；按键、按钮是加速落下；换位走弧线，不再直线平移。

**2. 手不再被拉长。** R05 的递卡、举卡、探针都靠大位移平移，靠近手腕一段被拉伸成橡皮手（拇指、手指变长）。R06 改为绕手腕刚性转动，再配合轻微放大（卡片朝你递近 4.5%、故障卡 3.5%），平移只留一小段。浏览网页的转轴从指尖移到手腕，指尖真正抬起再点下。

**3. 节奏。**

| 状态 | R06 的做法 |
|---|---|
| 待机 | 先看球 → 手指后收蓄力 → 弹一下 → 球带一点转动摆动后收住，眼睛轻轻跟球 → 看回你；8 秒处再看一眼球。其余时间安静 |
| 思考 | 目光落在全息节点，小跳到相邻节点，抬眼想一会儿，再回来看问号；托腮手不动 |
| 读文件 | 左、中、右三张卡依次读，每张里有两次小幅向右的阅读跳动；读完最后一张停一会儿再回到第一张 |
| 看图片 | 眼睛先到，笔沿弧线抬起移到第一处，落定后停看；再换到第二处；回位 |
| 写文件 | 手放在键上（即确认原图），三组长短不一的左右错开连敲，第三组用较慢的回车收尾，之后目光扫一遍屏幕上那行字；循环由 3.4 秒延长到 4.4 秒 |
| 验证 | 悬停 → 沿探针方向落下并轻压到位 → 接触时看读数等结果 → 抬起 → 再看读数 → 回到悬停 |
| 浏览网页 | 看目标面板 → 指尖抬起 → 点下 → 依次读中间和右边面板 |
| 工作中 | 两下短滚轨迹球，盯屏幕看，再做一次小修正；目光在屏幕上有小跳动 |
| 回答 | 先微收，再转腕递出并略放大，略过头后回稳；眼睛从卡片转向你，之后稳定持卡 |
| 等待回应 | 眼睛先看按钮 → 加速按下并停一下 → 松开回位 → 看向你；只按一次 |
| 遇到问题 | 轻微下沉蓄力 → 举起并略放大 → 略回落安定；眼睛先看卡片，再略向下地看向你 |
| 完成 | 不变，完全静止 |

**4. 补底透明度。** 图像生成的补底图在手和道具背后大面积是半透明的（透明度约 0–98%）。手一移开，桌宠背后的颜色就从这条缝透出来，在深色背景上就是一道灰色残影（R05 同样存在）。R06 在合成时把原图本来不透明的地方补成不透明，透明度过低的少量像素用周围颜色补齐。看图片的笔杆另外清掉了约 1 像素的旧描边残线。`generated/` 里的原始补底文件未修改。

**5. 幅度**（实际显示像素，相对原姿态的最大偏离）

| 状态 | R05 | R06 | 说明 |
|---|---|---|---|
| 待机 | 2.8 | 1.7 | 手指先后收 0.5 再弹出，来回约 2 |
| 看图片 | 3.2 | 2.5 | 带弧线与转角 |
| 写文件 | 2.4 | 1.7 | 按键抬起 3.4°/3.8°，回车 5.5° |
| 验证 | 3.9 | 2.7 | 一半来自手腕转动 |
| 浏览网页 | 2.2 | 1.6 | 指尖本身移动（R05 指尖固定） |
| 工作中 | 2.2 | 1.9 | |
| 回答 | 4.0 | 2.8 | 另有 4.5% 放大 |
| 等待回应 | 1.9 | 1.6 | |
| 遇到问题 | 2.5 | 2.5 | 另有 3.5% 放大 |

峰值整体略降，但到位更快、停得更干脆，眼睛从几乎不动变成有明确落点（R05 思考、读文件的目光每帧最多 0.2–0.3 像素，R06 跳视约 1–1.6 像素/帧）。是否“看得见”需要你在实际尺寸下判断；若觉得某个状态偏小，`tools/build_motion.py` 的 `pose()` 里改对应数值即可，单位就是显示像素。
