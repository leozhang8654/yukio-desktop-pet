## 用户确认抠图后的顺序

1. 按钮手部首先校准：补出手移开后露出的袖子、按钮背景；分离按钮顶面与固定底座；固定袖口；短行程按压。
2. 精修真正运动的选区与接触：笔与手、探针与手、卡片与手分别联动；键盘两手错开；轨迹球与手保持接触。读文件、完成状态主体先固定。
3. 露脸状态制作独立眼睛与眼皮。完成状态不补眼睛；头颈、家具始终固定。
4. 编码后重新读取，核对最大位移、接缝、允许区域外变化及循环。逐状态实际播放至少三轮；完成制作自检后，再由独立 Agent 检查并留下真实结论。
5. 动画完成并验收后，接入和安装另作独立交付。本阶段没有授权更换桌面 App、正式资源或发布内容。
