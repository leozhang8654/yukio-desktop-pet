第一次合成带入偏移的按钮线；第二、三次收紧蒙版前仍见轮廓接缝。中间文件保存在 candidates/experiments；用户随后指出最终图仍有按钮黑边台阶，确认上次验收漏检。现已沿生成指尖轮廓重新裁定蒙版，并完整恢复右侧按钮原像素；旧成品与旧报告存于 review/button-seam-fix/。没有重复生成整图。

修正后重新打开局部400%及800%对照、五背景图；原人物、问号、按钮与袖口关系保留。完整提示词见 prompts/11-contact.txt，生成候选与最终合成不能混用。

## 每张决策

- **idle**：磁悬浮球与底座分离符合设定；指尖朝向球面，保留。
- **thinking**：托腮接触、问号和双分支节点完整，保留。
- **read_file**：三张文件卡边框与文件夹符号完整；交叠手透过投影可见，保留。
- **view_image**：检查笔指向图片内，握持和透光台合理，保留。
- **write_file**：两侧键盘均落在桌面，指尖接近键帽，代码符号完整，保留。
- **verify**：探针指向模块测试圆环，手柄握持及模块支撑明确，保留。
- **read_web**：三面扇形投影和地球、链条完整；链条图标的断口是链接符号画法，不误判为损坏，保留。
- **default_work**：手接触轨迹球，显示器背面朝观众、支架落桌合理，保留。
- **respond**：持卡边缘与信封完整，递交姿态、原高光保留。
- **task_complete**：遮脸趴桌、叠袖和对号牌保留；固定桌前灯条位置与其他状态存在差异，系列一致性待处理。

- **failed**：警告三角与叹号完整，持卡关系及轻微失落表情合理，保留。
