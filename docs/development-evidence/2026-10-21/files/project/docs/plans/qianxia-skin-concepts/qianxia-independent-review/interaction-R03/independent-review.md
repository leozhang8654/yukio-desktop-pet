## 必须修复的问题

### R03-A01：独立透明背景残点（中等，阻断静态交付）

- 位置：以右侧吊牌之外空白为最明显诊断区域，x777–815,y1127–1160；另包括右上x977–991,y63–90、x271–283,y771、鞋外x579–582,y1482–1483等。逐块范围已在冻结的 `alpha-components.json` 中列出。
- 证据：独立支持域图及 `stray-600.png` 实际显示这些点位于人物、细带、发梢和鞋之外，没有可解释为人物装饰的形状或连接关系。正常合成中它们极淡，不能声称肉眼看到了明显亮点；支持域增强用于定位、原图语义对照用于判别。
- 重算结果：alpha>0共89个连通块；主体770571像素，其余88块合计166像素，alpha最大2（多为1）。与制作方报告一致。`qa/report.json` 的 `passed:false` 正确；0漏洞/0透明背景误选只说明该mask相对候选本身的结构，不能洗掉候选已有的alpha残留。
- 修复建议：按已确认无人物语义的独立背景块局部清alpha，保持人物RGB、主轮廓抗锯齿、全部发梢和真实配饰；不要全图阈值截断或整图重生。将修正输出另存新轮次，重新生成mask、机器检查、多背景证据及冻结哈希，再复核残点与头饰/细带/鞋底回归。
