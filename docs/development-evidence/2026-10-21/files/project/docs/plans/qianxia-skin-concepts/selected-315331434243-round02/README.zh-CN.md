# 千夏：第二轮静态设计修改

已选组合：`315331434243`。本轮为 12 张透明静态候选，尚未分层、制作动画或接入 App。

## 本轮修改

- 脸型：第一遍微调后用户仍认为太扁，因此再次增加下半脸空间、收窄两侧脸颊，保留圆润 Q 版轮廓；12 张采用修正后的轨迹球图作为比例参考。
- 鞋子略缩小；两只收纳盒移到画面右下，兔子底座保留在左侧。
- 待机：改为有滑槽、可推动按钮的小型机械滑块玩具，后续可通过手部与滑块的小幅平移表达推回动作。
- 思考：保留托腮与节点图构思。
- 读文件：三个较大的屏幕整齐排列，显示面朝角色，双手不再点屏；后续只做扫视与独立眨眼。
- 看图：图案转为角色观看时的正向。
- 轨迹球：调整操作关系，增加面向角色的独立显示器。
- 回答、提问、完成及失败等面向用户的通知继续朝外。

[前后对照页](preview.html) 可切换上一版与本轮、预览底色以及显示尺寸。对照页依赖保留的相邻 round01 文件夹。
