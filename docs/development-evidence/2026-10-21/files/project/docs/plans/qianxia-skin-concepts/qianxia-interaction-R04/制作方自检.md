# R04 静态底图自检

依据用户 2026-10-13 新提供的设定图制作拖動/移动的纯人物姿势。R03 独立评审要求仅清理背景残点；人物大结构无必须重绘项。

本轮只将独立确认的 88 个背景残块（166 像素、alpha 1–2）设为透明；完整人物主连通块每个 RGBA 字节保留不变。没有腐蚀/膨胀/模糊轮廓。背景处理是用户指定抠图流程中的精修，未使用新生成替换已通过的角色形体。原始生成使用内置 imagegen，提示保存于 R03。

最终源图 1024×1536，PNG 已重新读取。机器检查为 1 连通块、0 不透明漏洞、0 全透明背景误选；该报告检查最终透明素材拓扑，不将它作为对原图无损的证明。原图差分另由 refinement.json 记录：除明确剔除背景外全部像素一致。

制作方已打开四背景、彩色叠加、轮廓，以及黑色手袖 200%、洋红鞋腿 200%；另对照 R03 白背景的手袖、鞋和完整人物。发型、发饰、两手相接、袖口、兔子包、挂饰、裙摆、袜腿、鞋轮廓在本次可视检查中未见新增缺损。源图半透明抗锯齿和原始 alpha 保留；不声称新绘图与设定图逐像素相同。

待独立复审，之后交用户确认底图。未制作动画、未替换桌面 App 或正式资源。
