# 打开聊天后自动放下完成牌

雪绪每约 0.5 秒确认前台 App 内正在显示的聊天。已举起的完成牌会收起；如果结果输出时聊天就在眼前，这一轮不再举牌。离开后不会重复提醒已看过的结果，下一轮未查看的完成结果仍会提醒。正在回答的问题不因打开聊天而被取消。

网页与扩展侧栏可以同时显示两条聊天，两条分别确认，不影响其他聊天的牌子。雪绪固定跟随另一条任务时，这项规则仍然生效。

## 支持入口与前提

- Claude / Codex App：保留本地会话选择记录识别，并使用同一套完成确认逻辑。
- Claude 网页聊天 `/chat/<id>`、Code `/code/<id>`，以及 Claude in Chrome 内嵌网页 `/cic/task/<id>`。
- ChatGPT 网页 `/c/<id>`、项目或自定义 GPT 内的 `/g/<id>/c/<id>`，Codex 网页任务 `/codex/tasks/<id>`。
- Chrome 扩展通过其**可见的内嵌聊天网页**识别；不要求给雪绪安装另一款扩展。扩展若不向系统提供聊天文档地址，则保持提醒。
- macOS：Chrome、Edge、Brave、Arc、Safari，以及 Claude / ChatGPT / Codex 原生应用入口。Windows：Chrome、Edge、Brave、Arc、Chromium，以及 Claude / ChatGPT / Codex 应用入口。具体客户端能否读到文档地址取决于其辅助功能实现。

只会确认雪绪已经跟随、会话 ID 能准确对应的任务。Claude 桌面 `local_…` 与转录 ID 使用本地记录的显式映射。不同云端/本地会话的 ID 不会凭相似标题合并；该功能不增加纯云端聊天的任务日志来源。后台标签、聊天历史链接、共享链接、首页和无法确认的会话不会触发放牌。

## macOS 启用

在雪绪设置中点击「启用浏览器自动放牌…」，在系统「隐私与安全性 → 辅助功能」允许雪绪。已有权限时自动生效。只在用户点击此按钮时请求权限，不在启动或后台回答问题时反复弹窗。

识别仅读取前台窗口内聊天文档的地址，不读取消息正文、Cookie、浏览记录，不切换标签页、不输入或发送内容。失去前台、读取失败或结果过期时停止确认，保留提醒。

## 验证与排查

macOS 使用 `YukioPlayer --open-chat`；Windows 使用 `python run.py --open-chat` 或 `Yukio.exe --open-chat`。将需要检查的聊天保持在前台执行诊断，输出权限状态、已识别文档的助手类型与会话 ID。

自动化回归覆盖 URL / 助手身份匹配、明确的桌面会话映射、拒绝历史/共享/伪造网址、隐藏文档、网页与扩展双聊天、查看结果后离开、下轮再次举牌，以及固定跟随其他任务时放牌。Windows 窗口层以夹具验证，不代表 Windows 实机验收。
