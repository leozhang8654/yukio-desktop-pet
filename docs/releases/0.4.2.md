# Yukio 0.4.2 — 设置面板新增退出按钮

- macOS 和 Windows 的右键设置面板新增「退出雪绪」按钮，点击即可正常退出程序。
- 「完成」仍只关闭设置面板；「收起雪绪」仍只隐藏角色。
- 保留 0.4.1 的回答回执修复：GPT 确认收到答案后，立即放下对应问题牌。

Right-click Yukio and choose **Quit Yukio** in settings to exit the app on macOS
or Windows. **Done** only closes settings. This release retains the 0.4.1 fix
that lowers question signs as soon as GPT confirms an answer.

macOS: `Yukio-0.4.2-macOS.dmg` or `Yukio-0.4.2-macOS.zip` (Apple silicon and Intel).
Windows: `Yukio-0.4.2-Windows-Setup.exe` (Windows 10/11, 64-bit).
Update feeds and `SHA256SUMS.txt` are included for package verification.
