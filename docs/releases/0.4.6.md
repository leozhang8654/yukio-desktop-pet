# Yukio 0.4.6：插件聊天、完成提醒与批准卡

- 对应聊天显示时，自动放下那一轮的完成牌，不必先点击雪绪；同一轮不会因为切走再次提醒。问号牌不会因此自动回答或批准。
- GPT 官方 Chrome 侧栏记住对应浏览器标签页，不再改去 GPT App。修复全屏重复标签、部分标签名称读取失败及较早聊天名称丢失。
- 标签页已关闭、改名、名称不唯一或尚未识别时，不猜测跳转；对应关系保留到雪绪退出。
- 批准申请显示为问号卡，先查看完整申请再选择；修复回答框粘贴、断线后保留输入、Windows 中文回执及 Claude 连接依赖。
- 包含千夏皮肤、专用拖动站姿、连续拖动落点修复，以及默认开启、可关闭的待机隐身。

Mac 为 Apple 芯片与 Intel 通用版；Windows 提供安装包、便携包和应用内更新文件。此前 0.4.4、0.4.5 的开发改动一并包含在本次发布中。

**已测范围：**Mac 219 项自动检查；实际外接屏识别 GPT 侧栏、收起不误认、重新打开恢复识别，正确记录一个原标签页。Windows 在 Windows 环境构建并检查安装、升级、回传和角色显示。详见[检查记录](../validation/plugin-signs-0.4.6.md)。

**尚未全部验证：**真实新一轮完成后“已经举牌再切回自动放下”、亲手点牌返回原标签页，以及 GPT／Claude／DeepSeek 所有网页、插件、App 和多屏组合。网页／插件批准接入仍为实验功能。本次发布不表示这些情况全部通过。

Mac 窗口识别需要有效的辅助功能许可；更换临时签名的程序后，系统可能要求移除旧条目再添加新版。当前用户桌面沿用已验证、已获许可的同一份程序。
