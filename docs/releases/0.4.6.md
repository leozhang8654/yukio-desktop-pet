# Yukio 0.4.6 修复候选：插件聊天与自动放牌

- 完成牌已经举起时，不必先点击；对应聊天显示在屏幕上后，记为已读并放下。同一轮不会因为切走再次举牌，新一轮完成仍会提醒。
- GPT 官方 Chrome 侧边栏按完整聊天名称识别，记录所在浏览器标签页。点击该聊天的入口时回到原标签页，不再发送到 GPT App。
- 重新启动后仍载入最近一天内记录的聊天名称；较早完成的插件聊天也能对应，但不会重放旧的完成提醒。
- 同名、截断标题、已关闭或改名的标签页不猜测跳转。未观察到原标签页时，需要先在浏览器打开对应聊天；标签页对应关系只保留在本次运行期间。
- 保留 0.4.5 的千夏皮肤、拖动站姿及待机隐身。

macOS 需要有效的辅助功能许可才能识别窗口。临时签名的新程序可能需要重新允许，系统设置显示旧版已允许并不能证明当前程序可读取。测试版 build 27；实际验证记录另列，不能把自动检查当作所有浏览器和双屏组合均已实测。
