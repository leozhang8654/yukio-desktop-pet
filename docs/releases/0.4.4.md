# Yukio 0.4.4 测试版 — 批准申请与回答修复

- Mac 回答小窗口支持直接粘贴、复制、剪切和全选，无需先打开助手窗口。已实际验证中文、多行与表情粘贴。
- GPT、Claude、DeepSeek 的已连接入口增加批准申请问号牌。查看完整申请后，由用户决定允许这一次或拒绝；申请过期或内容改变时停止发送。
- Claude Code 增加 PermissionRequest 连接，并修复安装时遗漏配套运行文件的问题。Windows 增加同样的本地连接，修复偶发连接误判。
- Deep Code 增加当前申请批次的允许／拒绝，保留原有模式，不授予长期权限。
- 网页及官方 GPT／Claude Chrome 插件接入仍属试验功能，只能处理能识别的真实申请控件。GPT 插件普通问题的备用回传会核对当前聊天与完整问题，无法核对时保留回答并提示到原聊天处理。

**验收限制：**已通过本地自动检查、Mac 实际粘贴与问号牌显示，以及 Windows 环境中的安装、回传和显示检查。真实 GPT／Claude／DeepSeek 网页、插件及所有第三方 App 的完整往返仍未全面验证。此版尚未作为正式更新发布，不承诺所有软件和双屏组合均适用。

详情见[回答与批准说明](../../YukioPlayer/Resources/BACKGROUND-ANSWERS.md)及[测试记录](../validation/approval-cards.md)。
