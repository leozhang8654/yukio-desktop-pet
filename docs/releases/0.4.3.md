# Yukio 0.4.3 — 聊天放牌与协作任务工作显示修复

- Mac：聊天内容露在任意屏幕时，可放下对应完成牌；在另一块屏幕操作别的软件也适用。修复安静阅读十秒后失效、GPT 插件顶部信息读不到、程序坞透明区域被误当遮挡，以及 Claude App 聊天地址漏识别的问题。
- Mac 与 Windows：协助助手完成自己的部分时不再单独举完成牌，避免挡住其他工作动作；正确显示父聊天名称，大记录重启后也保持正确对应。收到明确开始记录后立即进入工作状态。
- 保留普通聊天的完成提醒、问题卡回答、退出按钮和应用内更新。

范围：自动放牌只适用于能与雪绪正在跟随的会话对应的聊天。GPT 标题回退存在同名限制。Windows 保留前台窗口识别方式，本版不宣称具备 Mac 双屏遮挡判断。未保证任意网页、同名聊天、拔插显示器或睡眠唤醒场景均通过实测。

macOS acknowledges matching tracked chats across displays and fixes current GPT extension / Claude app recognition. Both platforms separate helper identity and suppress internal helper completion signs. Windows still uses foreground-window detection.

Downloads: `Yukio-0.4.3-macOS.dmg`, `Yukio-0.4.3-macOS.zip` (Apple silicon + Intel), `Yukio-0.4.3-Windows-Setup.exe` (Windows 10/11 x64). Signed update feeds and `SHA256SUMS.txt` accompany the release.
