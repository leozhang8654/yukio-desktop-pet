# Yukio 0.4.5 — 千夏皮肤与拖动站姿 / Qianxia skin and held pose

- **两套皮肤**：在「设置 → 显示 → 皮肤」选择雪绪或千夏，立即切换并保留选择。千夏包含 12 种动作及适用状态的独立眨眼。
- **千夏拖动站姿**：使用提供的透明站姿，拎起时随移动摆动，松手晃停后恢复当前动作。修复 macOS 连续拖动后落点偏移。
- **待机隐身**：默认开启；工作、提问、完成和错误会自动现形。设置中可关闭，手动收起仍优先。
- **批准与回答**：批准申请展示问号牌与允许／拒绝选项；修复回答框粘贴和 Windows 中文批准回执，安装 Claude Hook 时带上所需运行依赖。

Switch between Yukio and Qianxia in Settings. The new skin includes twelve activities, independent blinking where provided, and a standing pose that swings during dragging. Release restores the current activity without position drift. Hide when idle is now enabled by default and can be disabled in Settings. This release also improves approval cards, answer pasting and UTF-8 Windows hook receipts.

网页／插件入口仍按[回答与批准说明](https://github.com/leozhang8654/yukio-desktop-pet/blob/v0.4.5/YukioPlayer/Resources/BACKGROUND-ANSWERS.md)中的已验证范围工作；不能推定任意网页聊天都支持后台批准。Web/plugin integrations retain their documented compatibility limits.

- macOS 13+，Apple 芯片和 Intel 通用：`Yukio-0.4.5-macOS.dmg` 或 `Yukio-0.4.5-macOS.zip`，build 26。
- Windows 10 / 11 x64：`Yukio-0.4.5-Windows-Setup.exe`。已有安装可使用应用内更新；便携包也保留提供。
- `SHA256SUMS.txt` 用于核对下载；`validation.json` 记录源码提交、同源资源及两端原生验证。macOS 更新包和更新列表带 Sparkle 签名。

macOS 包沿用临时签名，Windows 包未购买代码签名证书；首次运行的放行步骤见项目 README。
