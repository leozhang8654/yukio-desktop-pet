# Yukio 0.4.0 — 应用内更新 / In-app updates

- 自动检查正式版本，展示更新说明。无需每次访问下载页。
- 点击“更新并重启”后下载并安装；可选择稍后，保留原有设置。
- 设置中可关闭自动检查，也可随时手动检查。
- macOS 使用 Sparkle 签名更新；Windows 使用 Velopack 安装和更新。
- 旧版用户需要先安装一次 0.4.0，此后可直接在应用内升级。

Automatically check for stable releases and show what changed. Click Update and
restart to install, or postpone. Preferences are retained. Automatic checks can
be disabled in settings; manual checking is always available.

Windows users: install the new Setup executable once instead of launching the
old standalone EXE. macOS users: replace the old app once with this version.
Future updates happen inside Yukio. Initial OS trust prompts may still appear:
these builds do not yet have Developer ID notarization / Authenticode signing.
