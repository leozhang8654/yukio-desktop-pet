# Yukio 0.4.1 — 回答确认后放下问题牌

- 在雪绪的问题卡片里回答时，GPT 确认收到答案后立即放下对应的 ❓ 问号牌，不再等待会话日志刷新或动画的最短保持时间。
- 直接在 GPT 聊天中回答时，会话记录出现已接收的回答后也立即放下问号牌。
- 发送失败或尚未收到回执时继续举牌，并保留答案供重试。其他问题和完成牌不受影响。

When GPT confirms a reply sent from Yukio's question card, she lowers that
question sign immediately. A reply accepted in the GPT chat has the same effect
as soon as it appears in the session log. Failed or unconfirmed sends leave the
question visible for retry.

macOS: `Yukio-0.4.1-macOS.dmg` or `Yukio-0.4.1-macOS.zip` (Apple silicon and Intel).
Windows: `Yukio-0.4.1-Windows-Setup.exe` (Windows 10/11, 64-bit).
The release also includes update feeds and `SHA256SUMS.txt` for package verification.
