# Yukio 0.3.9 · 任务气泡与人物同步缩放

以 100% 时的现有尺寸为基准，任务气泡和上方通知卡跟随雪绪的大小同步变化。文字、描边、间距及点击区域保持同一比例。Windows 调整大小时会立即重绘，不再先让气泡消失再淡入。

## 下载

- `Yukio-0.3.9-macOS.dmg`（Apple silicon / Intel 通用，拖拽安装）
- `Yukio-0.3.9-macOS.zip`（同一 App 的 ZIP 备选包）
- `Yukio-0.3.9-Windows.exe`（Windows 10 / 11，64 位）
- `SHA256SUMS.txt`（上述下载文件的 SHA-256）

下载前核对发布页显示的版本和校验值。macOS 用户安装新版前先退出正在运行的雪绪，再拖入并选择替换。Windows 版由 Windows 构建环境打包并运行原生窗口检查。
