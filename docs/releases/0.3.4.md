# Yukio 0.3.4 · 修复 GPT 回答与权限循环

macOS 和 Windows 的 GPT / Codex 问题卡改为后台直传：不切换聊天窗口、不改粘贴板、不模拟按键。macOS 回答不再要求辅助功能权限。

修复当前桌面版把聊天记录存入 canonical history 后，雪绪误判待答问题为“已结束”的问题。提交前核对聊天、问题编号和正文；重复或过期问题不发送。失败保留输入并允许重试，收到回执后才收起对应问题。

## 支持范围

- GPT：本机运行中的 Codex 桌面任务；普通 ChatGPT 网站未接入。
- macOS 的 Claude Code / Deep Code 后台连接需要按应用菜单中的回答说明配置。
- Windows 的 Claude / Deep Code 沿用原有发送方式；本次后台通道同步针对 GPT / Codex。
- 多题阻塞式问题仍需回原聊天完成，不会用普通消息代替整组回答。

## 验证

- macOS：175 项 Swift 测试通过；用户从安装版问题卡点击“测试成功”，真实聊天收到对应回传。
- Windows：本地 234 项检查通过（其中 1 项 Windows 专用超时检查仅在 Windows runner 执行）。发布构建另外测试 Windows 命名管道和实际打包 exe 的完整协议收发。
- 命名管道检查覆盖新旧聊天格式、分片读取、错误回执、过期问题，以及阻塞题的接收确认。
- 现有窗口、设置和 100% / 150% 缩放检查继续保留；发布下载复验包含 200% 缩放。
